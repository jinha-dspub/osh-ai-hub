# 품질·검증 기록

대상: demo-dataset / 0.0.0-demo · 합성 DEMO 파일만 해당
검사 기준일: 2026-09-19

| 검사 | 결과 | 범위 |
|---|---|---|
| JSON/CSV 구문 | 통과 | 템플릿 파일 파싱·열 개수 |
| 크기·SHA-256 | 통과 | files.csv와 preview.csv 바이트 비교 |
| 표 행 수 | 3행 | CSV 파서 기준, 헤더 제외 |
| 기본키 중복·결측 | 0건 | 합성 record_id |
| 외래키 | 해당 없음 | 단일 합성 표 |
| MD/XLSX 원문 연결 | 해당 없음 | 원문 없음 |
| 실제 자료 내용·개인정보 검수 | 미검사 | 실제 자료 교체 후 별도 수행 |
| 검색/AI 평가 | 미실행 | 앱·모델 없음 |

## 실제 패키지에서 채울 기록

- 검사 버전·날짜·환경·코드 리비전·실행 명령·결과 파일:
- 선언 통계 / 재집계 / 차이와 원인:
- 열별 결측 개수·분모, 타입·허용 값·단위 위반:
- 기본키 중복·누락, 연결 누락·고아 문서·잘못된 부모 참조:
- 중복 자료·학습 분할 간 중복/정답 누출:
- 내용 검수 대상·표본 선정·검토 주체·검증 범위:
- 개인정보·재식별 검토 범위와 미검토 영역:
- 실패/미실행 검사, 알려진 오류, 다음 조치:

실제 파일을 교체하면 템플릿의 통과 기록을 재사용하지 말고 재검사한다. 미검사를 0건·통과라고 기록하지 않는다. 실패 상세에 개인정보가 있으면 비공개로 관리한다.
