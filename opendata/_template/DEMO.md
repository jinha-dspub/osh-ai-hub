# DEMO 연결 명세 양식

상태: **not_planned · 실행 앱 없음**. 아래는 작성 항목이며 동작하는 API가 아니다.

## 목적·입력·결과

- 누가 어떤 자료를 검색/비교하는가:
- 소개 페이지에서 안내할 활용 순서:
- 실제 자료·합성 예시·AI 생성 결과 구분:
- 구현 범위 / 미구현:

| 항목 | 작성할 내용 |
|---|---|
| 검색어 | 타입·길이·빈 값 처리·민감정보 입력 제한 |
| 필터 | 실제 열·허용 값·다중 선택·같은 축 OR/다른 축 AND 여부 |
| 페이지네이션 | 정렬·페이지 크기 상한·전체 건수의 의미 |
| 상세 | 안정적인 ID·원문 근거·AI 가공·검수 상태 |
| API | 메서드·경로·요청/응답 JSON 예·오류; 합성 예시는 DEMO 표시 |
| 접근 | 역할별 검색·상세·파일 권한과 서버 검증 |
| 파일 | 등록된 파일 ID만 허용, 권한 확인 후 Storage 직접 다운로드 |

## 화면·오류

소개는 표 예시·출처·한계·활용법에 집중하고 작동하지 않는 검색창을 두지 않는다. 실제 DEMO는 처음/로딩/성공/빈 결과/입력 오류/권한 없음/시간 초과/예산 소진 상태를 구분한다. 데스크톱·360px 모바일, 키보드·포커스·표 스크롤을 확인한다.

## 실행·운영 인계

- 실제 실행 파일·의존성 버전·설치/시작/종료 명령:
- 자료 상대 경로·필요한 환경변수 이름:
- loopback 테스트 주소·기존 포트와 충돌 여부:
- /demo/<slug>/ 하위 자원·API 경로 검증:
- 서버 권한·동시성·시간 초과·공유 유료 예산 연결:
- 외부 API가 없을 때 동작과 대안:
- 로컬 검사 / 운영 배포 / 실제 이용 확인 결과:

필요할 때 demo/에 참조 구현을 추가한다. 이 양식만으로 운영 프로세스·.3 nginx·UFW를 변경하지 않는다.
