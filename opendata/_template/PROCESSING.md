# 가공 과정·재현 기록

현재는 템플릿용 고정 합성 값이며 실제 문서 분석·모델 호출 결과가 아니다. 실제 자료를 가공하면 다음을 채운다.

1. 입력 파일 버전·해시와 출력 버전. 원본은 덮어쓰지 않음.
2. 처리 순서: 추출 → ID 연결 → 정규화 → 검증 → 미리보기/배포본 생성.
3. 실행 스크립트·런타임·의존성 버전·재현 명령. 없는 파일을 실행 가능하다고 하지 않음.
4. XLSX 시트/셀 범위·수식 처리, MD 인코딩·전처리, 단위·결측·복수 값 규칙.
5. 원문과 결과를 연결하는 키·근거, 실패·제외 행과 이유.
6. AI 사용 시 모델/리비전·프롬프트 버전/해시·실행 날짜·입력 범위·사람 검토 범위.
7. 외부 전송 범위·실제 측정 비용·비용 제한. 미측정은 미측정으로 표기.
8. 비결정성·재실행 시 변경 정책·환경 차이.

임베딩이 있으면 indexes/README.md에 모델/차원/문서·질의 작업 설정/청크 키/입력 해시/정규화/재생성 방법을 추가한다. 원문과 임베딩의 접근 정책도 확인한다.
