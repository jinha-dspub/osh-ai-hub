# 출처·이용 조건·접근 범위

문서의 상태값만으로 실제 API·Storage 접근 권한이 부여되지는 않는다.

## 실제 자료에서 확인할 근거

- 원문 제공자·수집 경로·수집일·이용 조건 문서/URL:
- 가공 주체·가공 라벨/요약/임베딩의 권리 및 재배포 조건:
- 허용 목적·인용·보관/삭제/철회 처리 주체와 방법:
- 개인정보/재식별 검수 대상·방법·날짜·근거:
- 외부 AI API 전송이 허용된 정보와 근거:
- 이미 승인된 공개 범위·확인 주체·날짜(공개 가능한 정보만):
- 미확정 사항:

현재는 원문 없는 합성 템플릿이다. 실제 데이터의 이용 권리를 부여하지 않는다. 공개된 출처라는 이유만으로 모든 가공·재배포가 허용된다고 쓰지 않는다. 라이선스를 확인하지 못했다면 미확인으로 남긴다.

## 기능별 접근

| 기능 | 상태 | 이용 대상 | 근거 / 미완료 |
|---|---|---|---|
| 소개 | draft | admin | 실제 메타데이터·출처 검토 전 |
| 3행 표 | draft | admin | 합성 양식만 존재. 실제 행/열은 별도 검토 |
| 검색·상세 DEMO | not_planned | none | 실행 앱 없음 |
| 원문 다운로드 | not_planned | none | 실제 배포 파일·Storage 없음 |

원문·사건번호·요약·측정치·임베딩을 포함해 허용 범위를 기록한다. 미리보기 후보도 승인 전에는 비공개로 전달한다. Google 로그인은 자료 승인이나 연구 참여 동의와 별개다. 익명·일반 회원·승인 이용자·관리자의 직접 API/파일 접근을 서버에서 강제한다.

Hugging Face 게시 계획 없음. 변경할 때는 별도 배포 범위를 검토한다.
