# 공개 화면과 관리자 초안

2026-09-17. 디자인 가이드의 준비 상태 표시는 관리자 검토 화면에서 유지하고, 일반 방문자는 사용 가능한 기능만 탐색하도록 정리했다.

- 공개: HWPX, 건강검진 확인, COPD 검색 바로가기, DEMO 데이터·샘플 API.
- 관리자 초안: 미연결 분석 앱 3개, 모델 카드, 이미지 Playground·추론 API 소개, 개인 API 키·사용량 화면, 비활성 원본 다운로드 버튼.
- 관리자 시작 주소: `/admin/drafts`. `/models`, `/models/[slug]`, `/playground`, `/account/*`도 페이지별 권한 확인 후 렌더링한다.
- 서버가 Supabase `getUser()`로 사용자를 검증하고 기존 `role_assignments`에서 해당 사용자 UUID의 `admin` 행을 조회한다. 프로필·user_metadata·쿠키 플래그·URL 매개변수로 권한을 부여하지 않는다.
- 인증 미설정, 로그인 없음, 역할 테이블 미설정·조회 오류는 초안 비공개/404로 처리한다. 사용자별 결과를 전역 캐시에 저장하지 않는다.
- 기존 마이그레이션에 역할 테이블 및 본인 역할 조회 RLS가 정의되어 있다. 이번 작업은 DB 또는 역할을 변경하지 않았다. Google OAuth 설정과 실제 관리자 계정 등록은 다음 작업으로 미뤘다. 설정 완료 전에는 관리자도 초안을 열 수 없다.
- 로그인·원본 다운로드·다중 필터의 진행 중 코드는 Git 제외 `local_asset/pending-google-download-filters-20260917/`에 별도 보관했다. 이번 배포에는 포함하지 않는다.
- Hugging Face는 게시 계획 없음으로 표시한다. 작동하는 합성 예제의 DEMO 표시는 유지한다.

브리프: 방문자가 실행 가능한 작업을 고르는 것이 목적이다. 기존 카드 스타일·반응형 레이아웃을 유지하고 빈 비활성 카드나 가짜 인증을 추가하지 않는다. 관리자 인증 통합은 외부 설정 후 별도 검증이 필요하다.

권한 확인 참고: https://supabase.com/docs/reference/javascript/auth-getuser

공통 loading boundary는 데이터 탐색 경로로 한정했다. 관리자 초안은 권한 판단 전에 loading 응답을 스트리밍하지 않으며, 거부된 직접 HTTP 요청은 404를 반환한다.
