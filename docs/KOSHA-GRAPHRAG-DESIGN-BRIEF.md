# KOSHA GUIDE 그래프 검색 디자인 브리프

상태: 구현 중 (로컬 검증 완료, 운영 주소 확인 전)
작성일: 2026-10-06
기준: [OSH AI Hub 디자인 가이드](DESIGN-GUIDELINES.md)
인수 검토: [KOSHA-GRAPHRAG-INTAKE-REVIEW.md](KOSHA-GRAPHRAG-INTAKE-REVIEW.md)

## 목적

- 사용하는 사람: 현장 안전 담당자, 연구자. 현장 말로 묻는 사람.
- 해결할 일 한 가지: "이 작업·설비에 대해 KOSHA GUIDE와 법령이 뭐라고 하나"를 지침 발췌와 조문 원문으로 찾는다.
- 도구 설명 한 문장: 기술지침 658건의 본문 18,659구간을 낱말·용어 확장·개념 그래프로 검색하고, 선택한 발췌와 조문만 근거로 Claude가 짧게 답한다.
- 이번 작업 범위: 검색 화면(`/demo/kosha-guide-graphrag/`), 소개 페이지(`/datasets/kosha-guide-graphrag`), 관문 API. 제작자의 서술문 점검 MVP는 옮기지 않았고 다운로드는 열지 않았다.

## OSH Family Design 적용

- 적용 키트 버전: OSH Family Design 1.0 (`design/osh-family/osh-family.css` + `web/app/globals.css`).
- 공통 색상·Noto Sans KR Variable·카드 12px·버튼/입력 7px 적용: 예. 새 색은 형광펜(`mark`, `#fff2d6` DEMO 배지색)만 추가.
- 폰트 실제 로드 확인: 헤드리스 Chromium에서 `document.fonts` 로 'Noto Sans KR Variable' 로드 확인(데스크톱·390px).
- 앱에 맞게 달라지는 레이아웃/작업 순서: 검색 → 결과 목록(왼쪽) + 관련 조문·연관 개념(오른쪽 340px) → AI 답변 카드는 결과 위. 900px 이하는 한 열.
- 공통 스타일 예외와 이유: 결과 번호 배지(`kg-n`)·관계 버튼(`kg-edge`)은 이 도구 전용 요소. 토큰만 쓰고 새 색은 없다.

## 입력과 결과

| 항목 | 결정 내용 |
|---|---|
| 입력 자료·형식·용량 | 검색어 1~200자, 분야 선택(6종), 페이지(최대 5). AI 질문 2~300자 + 체크한 발췌 1~6개 + 조문 0~3개 |
| 주요 행동 버튼 | "검색" 하나. 결과 안에서 "발췌 전체 보기", AI 카드에서 "발췌 N개로 답변" |
| 결과 형식 | 구간 카드(지침명·분야·제목 경로·원문 쪽·발췌·인용 조문 칩), 오른쪽에 조문 카드(원문 발췌 → 전체)와 개체 관계 목록 |
| 다운로드 내용 | 소개 페이지에서 인계 패키지 전체 zip·핵심 zip을 60초 서명 주소로(소유자 결정 2026-10-06) |
| 근거·출처 표시 | 발췌마다 지침 번호·제목·원문 쪽. 조문은 법령명·조번호·시행일. AI 문장마다 근거 번호 버튼(G1·L1)으로 해당 카드로 이동. 근거 없는 문장은 서버가 삭제하고 개수를 표시 |
| 자료 전송·보관·삭제 | AI 답변 때만 질문·선택 발췌·조문이 Anthropic API로 간다(화면에 명시). 서버는 저장하지 않고 예산 장부에 금액만 남긴다 |
| 로그인·권한 | 공개(소유자 결정 2026-10-06). 소개 페이지는 `koshaGraphragPublic`으로 전환 |

## 실제 연결 범위

- 실제로 작동하는 기능: BM25 검색(패키지 색인 그대로, 조사 붙은 낱말 허용) + 의미(벡터) 채널 RRF 융합(루프백 임베딩 서비스), 통제어휘 확장(아시바→비계·작업발판, 공구리→콘크리트), 개념 매칭, 개체 관계 그래프 탐색(1단계 패키지 + 2단계 Claude 추출), 지침→조문 원문, 조문→판례 번호, Claude 답변(구조화 출력 + 인용 검증), 맥락 검색 탭(질문 이해 → 그래프·커뮤니티·발췌·조문 → 근거 인용 답변), 하루·기기별 한도.
- DEMO 자료·예시 결과: 없음. 모두 실제 자료. 예시 검색어 5개는 버튼으로 제공.
- 연결 준비 중인 기능: 커뮤니티 보고서(배치 완료 후 v3에서 맥락 검색 근거 C#로 등장). 판례 번호는 글자로만 표시.
- 확인하지 못한 외부 동작: osh.ai.kr → tools.osh.ai.kr → .6 경로의 운영 주소 응답, `.3` 요청 제한과 AI 응답 지연(로컬 8초)의 상호작용.

## 화면 구성

- 데스크톱: 제목·설명 → 검색 패널(검색어·분야·버튼·예시) → 요약 줄(건수·용어 확장) → AI 답변 카드 → 결과 카드 10개 → 페이지 이동. 오른쪽: 관련 조문(체크 가능) → 연관 개념.
- 모바일: 같은 순서로 한 열. 오른쪽 패널이 결과 뒤로 간다. 390px 가로 넘침 0.
- 공유할 화면·파일 링크: `/demo/kosha-guide-graphrag/?q=아시바 안전난간` (주소에 검색 상태 유지).
- 기존 가이드와 다른 부분 및 이유: 결과 카드 안에 체크박스(AI 근거 선택)를 둔다. 답변이 어떤 글을 읽었는지 사용자가 정하게 하기 위해서다.

| 상태 | 표시 문구 | 가능한 행동 |
|---|---|---|
| 초기 | 설명 + 예시 검색어 | 검색어 입력, 예시 선택 |
| 입력 오류 | "검색어는 1자 이상 200자 이하로 적어 주세요." 등 서버 문구를 그대로 | 고쳐서 다시 검색 |
| 업로드·처리 중 | 버튼 "검색 중…", "답변 만드는 중…", "불러오는 중…" (비활성) | 대기 |
| 성공 | "N개 구간이 '…'에 맞습니다" + 결과 | 발췌 보기, 조문 보기, AI 답변 |
| 빈 결과 | "맞는 구간이 없습니다. 다른 말로 바꾸거나 분야를 '전체'로 해 보세요." | 재검색 |
| 실패·부분 실패 | 503 "검색 자료를 불러오지 못했습니다", 429 한도 문구, 422 "AI가 … 거절했습니다", 근거 부족 시 "선택한 자료만으로는 충분히 답하지 못했습니다" | 재시도, 발췌·조문 변경 |
| 인증·권한 필요 | 관문 403 "인증된 관문을 통해 접속해 주세요." | .3 Basic 인증 |

## 결정과 검증

- 사용자와 합의한 사항: 2026-10-06 소유자가 "Sonnet으로, 제안대로(모델 없는 그래프RAG 검색 + Claude 답변)" 결정. 제작자 점검 MVP는 쓰지 않음.
- 임시 가정: 하루 한도 3,000원(`KOSHA_GRAPHRAG_AI_DAILY_KRW`), 기기별 하루 20회, 동시 2건. 호출 1건 실측 64원(예약 141원).
- 사용자 결정이 필요한 핵심 사항: (1) 공개 범위 — 소개 페이지 공개(`koshaGraphragPublic`)와 로그인 없는 DEMO(`OSH_PUBLIC_DEMOS`에 `kosha-guide-graphrag` 추가). (2) KOSHA GUIDE 본문 다운로드 여부.
- 모바일·키보드·대비 확인: Chromium 1280·390px 스크린샷, 가로 넘침 0, 콘솔 오류 0. 카드·조문 항목에 `tabIndex=-1` 포커스 이동, 체크박스·버튼은 기본 포커스. 실제 기기·스크린리더 확인은 안 함.
- 코드·브라우저 검증 결과: ai-api `ruff` 통과, `pytest` 158 통과(판례 NAS 경로 관련 기존 실패 `test_lanyard.py` 제외). web `lint`(기존 경고 1), `typecheck`, `vitest` 63 통과, `next build` 통과. 로컬 관문(127.0.0.1:8795)에서 화면·검색·조문·실제 Claude 답변 1건 확인.
- 미해결 사항: 운영 주소 확인, 의미 검색, 판례 DEMO 연결, 다운로드.
- 운영 배포 여부: NAS `kosha-guide-graphrag/serving/current` 생성, `osh-demo` 서비스에 등록·재시작. 공개 플래그는 꺼 둠.

실제 개인정보를 브리프나 공유 이미지에 포함하지 않는다. 예시 콘텐츠에는 DEMO를 표시한다.
