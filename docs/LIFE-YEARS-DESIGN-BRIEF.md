# 고용보험–건보 집계표·손실연수 계산 DEMO

기준: [디자인 가이드](DESIGN-GUIDELINES.md), [브리프 양식](DESIGN-BRIEF-TEMPLATE.md)

## 목적과 범위

연구자가 집계표 구조를 확인하고 합성 예제로 생명표·손실연수·YPLL을 계산한다.
사용자가 준비한 `/home/shield/data_station/tmp/osh_ai_kr` 패키지를 다른 자료처럼 등록하도록 요청했다.
`/datasets/ei-nhis-life-years-lost` 소개와 `/demo/ei-nhis-life-years-lost/` 계산 화면, 소형 가이드·양식·코드 다운로드를 연결한다.
원본 0.1.0-local(2026-10-30)은 보존하고 Hub 배포본은 2026-11-04.v1로 구분한다.

## OSH Family Design과 화면

OSH Family Design 1.0의 색·로컬 Noto Sans KR·카드·버튼을 유지한다.
소개는 목적 → 활용 3단계 → DEMO 3행 표 → 다운로드 → 출처·한계 → 입력 처리 안내다.
계산 화면은 제작자가 제공한 구성(집계 가이드 → 조건·계산 결과 → 논문 보고값 → 파일)을 유지한다.
모바일은 한 열이며 넓은 결과표는 내부 스크롤한다. 기존 앱의 JavaScript는 전달된 검증본 자산으로 보존하고 Hub 소개는 TypeScript, 계산 API는 Python으로 연결한다.

| 항목 | 구현 |
|---|---|
| 입력 | 합성 예제 9개 또는 집계 JSON 최대 10MB, 기준연령 60·64·65, 기준집단 |
| 주요 행동 | 집계표로 계산 |
| 결과 | 지표 표·차트·생명표, 결과 CSV·결과/설정 JSON·입력 JSON·생명표 CSV |
| 근거 | 제공 학위논문 방법 2.3.2·고찰 4.11·표 7/18/19. 원문 공개 URL 미제공 |
| 자료 구분 | 예제 9개는 synthetic, 표 7의 33행은 실제 보고값. 실제 연령별 반출 집계자료 없음 |
| 전송·보관 | OSH Python 서버 메모리에서 계산, 입력·결과 파일 저장 없음, 외부 AI 호출 없음 |
| 다운로드 | 자료별 안내·빈 양식·코드·보고값 CSV. 모두 소형 정적 파일, 대용량 ZIP 프록시 없음 |
| 권한 | 기존 .3 관문·Origin 검사 유지. 직접 서버 접근 차단 |

## 상태

- 초기: 합성 예제 목록 로드 후 계산 활성화.
- 처리: 중복 실행 방지, 조건 변경 잠금.
- 완료: 입력·설정·실제/합성 구분과 계산 결과 표시.
- 오류: 입력 보존, 이전 결과 숨김. 형식·결측/비공개 셀·크기 오류와 재시도 안내.
- 서비스 장애: 검증한 배포본이 없거나 해시가 다르면 503, 동시 계산 2개 초과 시 429.

## 인수·검증

원본 `verify_package.py`의 파일 198개 해시·크기·행 수·키·사전 검사와 계산 테스트 8개를 실행해 통과했다.
계산식·데이터 값은 바꾸지 않는다. 소개 3행은 `preview.csv`와 일치한다.
정적 화면의 로컬 전용 문구와 base URL, 공개 메타데이터만 별도 배포본에서 조정한다.
입력 파일은 별도 저장하지 않고 소스·QA·인수 문서는 정적 허용 목록 밖에 둔다.
다운로드 코드·가이드에는 원 제작본의 실행 방법을 유지한다.

`prepare_life_years.py` → `/nas/bin/nas-put … serving …` → 다이제스트 고정 → `serving/current` 전환 → 공통 관문 재시작으로 배포한다.
원본/서비스 파일은 Git에 넣지 않는다. 소개 페이지와 관문 코드만 Git/Vercel에 반영한다.
원본은 `raw/data-station-handoff-20261104`, 서비스 배포본은 `serving/ei-nhis-life-years-lost-20261104-v1`이다.
156개 정적 자산·계산 코드 파일을 manifest SHA-256 `b3a8d9e529b36c64482f311cb1484cd1c8dc0c71a7a8d62d6183e411b4b2fd12`로 고정했다.
계산 코드·CSV 결합 코드·data/ 전체의 원본과 배포본 바이트 일치를 별도 확인했다.

### 로컬 검증 결과

- 격리된 배포 작업 트리에서 웹 lint(기존 unused-import 경고 1개)·typecheck·단위 테스트 66개·프로덕션 build 통과.
- 신규 API·관문·정적 파일 회귀 검사 32개 통과. 신규 Python 코드 lint 통과.
- 전체 Python 검사는 211개 통과, 기존 안전대 NAS 저장 관련 3개 실패. `CORPORATE-OHS-INTAKE-REVIEW.md`에 이전에도 기록된 실패이며 안전대 코드는 변경하지 않았다.
- 실제 Python 계산 API를 연결한 데스크톱·360px 모바일 브라우저 검사 통과: 목록·소개·3행 표·계산 결과·4종 결과 다운로드·10개 자료 다운로드·1년 단면 외삽 제한·비공개 셀 거부·키보드 실행·가로 넘침 없음.
- 기존 프록시와 포트를 유지하고 `osh-demo.service`에 새 경로를 반영했다.

### 운영 등록과 검증

- 등록 커밋 `8607030`을 GitHub main에 반영했고 Vercel 배포 성공 상태를 확인했다. 별도 작업 트리에서 이 등록에 필요한 파일만 커밋했으며, 원래 작업 폴더의 다른 미커밋 수정은 포함하지 않았다.
- `https://osh.ai.kr/datasets`에서 손실연수 검색으로 카드 표시, `/datasets/ei-nhis-life-years-lost` 소개 페이지 200, `/demo/ei-nhis-life-years-lost/` 계산 화면 200을 확인했다.
- 실제 운영 JS/CSS·CSV·계산 코드의 응답 바이트가 NAS 배포본과 일치한다. 65세 이전 계산이 3개 합성 집단을 반환했다.
- 실제 모바일 Chromium에서 합성 예제 9종 목록, 계산 실행·결과 CSV 다운로드, 가로 넘침 없음·브라우저 스크립트 오류 없음을 확인했다.
- 다른 Origin의 계산 요청 403, 잘못된 입력 400, 위조 사용자 헤더를 포함한 .6 직접 접근 403을 확인했다.
- 이 서버에서 기존 관문을 경유해 확인했다. 별도 외부 방문자의 Basic 인증 정책 및 운영 프록시를 통한 최대 10MB 입력은 별도로 검증하지 않았다.

## 확인되지 않은 사항

실제 집계자료로 논문 수치를 재현한 검증, 원천·가공물 라이선스, 패키지 연구책임자·대표 연구자·문의처·갱신 담당은 미확인이다.
