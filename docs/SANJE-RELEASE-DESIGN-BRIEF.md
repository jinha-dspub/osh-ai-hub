## 목적과 범위

연구자가 질환별 자료 소개에서 실제 검색 DEMO로 이동해 원문, 측정자료, 근무시간, 표준 라벨 후보를 확인하고 파일을 받는다. 공개 화면은 집계·활용 안내를 제공하고 실제 검색·원문·파일은 기존 .3 인증 관문 뒤에 둔다. Google 계정 로그인만으로 이 관문이 해제되지는 않는다.

원문 제공자는 근로복지공단(https://jilbyungcase.comwel.or.kr/)이다. 사용자가 확인한 연구자 표기는 **윤진하 · 연세대학교 산업보건연구소**이며, 별도 확인 전 대표/책임연구자 역할로 확대하지 않는다. 업데이트 일정은 미정이다.

## 화면과 디자인

OSH Family Design 1.0의 짙은 파란색, Noto Sans KR Variable, 카드·입력 스타일을 공유한다. 공개 목록은 산재 컬렉션 한 장 → 7개 질환 소개 → 인증된 검색 DEMO의 순서다. 기존 COPD 주소 `/datasets/copd`, `/demo/copd/`는 유지한다. 다른 질환은 `/datasets/sanje/{group}`, `/demo/sanje/{group}/`를 사용한다.

데스크톱은 검색창 → 다중 필터 → 결과 → 상세, 모바일은 같은 순서의 한 열이다. 연도·판정·직종·대조 상태는 같은 필터 안에서 OR, 서로 다른 필터 사이에서 AND로 결합한다. 라벨은 50개씩 나눠 조회하고 근무시간 근거와 자동 매핑 후보의 한계를 함께 표시한다.

초기에는 검색 조건을 안내하고, 검색 중에는 중복 실행을 막는다. 결과 없음과 요청 실패를 구분한다. 인증 실패는 관문 안내를 반환한다. 파일 서명 생성 실패는 재시도 가능한 오류를 표시한다. 실제 데이터를 합성 샘플로 설명하지 않으며, 검색 화면에는 DEMO 인터페이스임을 표시한다. 브라우저 자동화의 사례·라벨은 DEMO 합성 fixture다.

공개 COPD 3행 미리보기는 기존 공개 4개 필드만 유지했고 새 CSV와 대조했다(유해인자 구분자만 표시 정규화). 다른 질환의 개별 원문이나 라벨을 정적 번들에 포함하지 않는다.

## 데이터 인수와 다운로드

- 원본 ZIP SHA256: `d2069287a2b4946429bcbeb58433523586aaf1b2fbb06ddcb73592562b8ba287`
- 원본 스냅샷: `opendata/sanje/releases/2026-09-19.v1/` (Git 제외).
- 원본 내 매니페스트 348개 항목 해시 및 CSV 관계/집계를 검증했다. 루트 매니페스트 자체와 나중에 생성된 VALIDATION.json은 원본 매니페스트 목록에 없다는 점을 인수 기록에 남겼다.
- `ai-api/scripts/prepare_sanje.py`가 공개 집계 JSON과 로컬 읽기 전용 SQLite 라벨 인덱스를 만든다. 원본 파일을 수정하지 않는다.
- 원본의 미확정 연구자 정보는 보존하고 사용자 확인 정보를 별도 `HUB-RESEARCH-INFO.json`으로 ZIP에 덧붙인다. 그룹별 ZIP만으로 전체 원본 루트 매니페스트를 검증할 수 없음을 안내한다.
- Supabase **private** `sanje-research` 버킷, 버전/질환/해시별 경로에 56개 파일을 업로드하고 원격 바이트 SHA256을 모두 대조했다.
- 질환별 8개 파일: ZIP, cases.csv, case_texts.csv, exposure_measurements.csv, worktime.csv, worktime_records.csv, standard_labels.jsonl, metadata.jsonl.
- 인증된 API는 고정된 파일 ID만 허용하고 60초 서명 URL을 발급한다. 대용량 바이트는 브라우저가 Storage에서 직접 받는다. 버킷 공개 전환, 그룹 밖 경로, 다른 버전의 매니페스트는 거부한다.
- 기존 `copd-research` 파일과 `opendata/copd`는 복구용으로 유지한다. Hugging Face 게시 계획은 없다. 최종 라이선스·자료 내용 검수 완료를 주장하지 않는다.

## 실행과 버전 전환

후보 설정은 `local_asset/sanje/2026-09-19.v1/release.json`, 운영 포인터는 `local_asset/sanje-current.json`이다. 설정 파일·SQLite·원문은 Git에 넣지 않는다. 검증 중에는 `SANJE_RELEASE_CONFIG`로 후보 설정을 지정한다. 설정을 원자적으로 운영 포인터에 복사한 뒤 기존 `osh-demo.service`를 재시작한다. .3 nginx, 8103 포트와 기존 프록시 규칙은 변경하지 않는다.

복구할 때는 이전 포인터를 복원하고 서비스를 재시작한다. 첫 전환 이전 상태로 돌아가려면 운영 포인터를 다른 이름으로 보관하고 서비스 및 정적 DEMO 번들을 이전 Git 버전에서 복원한다. 데이터만 되돌리면 새 화면과 이전 API가 맞지 않을 수 있다.

질환 데이터는 최초 요청 시 메모리에 적재한다. 전체 라벨 JSONL은 메모리에 올리지 않고 SQLite에서 질환/사례별로 조회한다. 인수본에는 임베딩이 없어 최초 구현은 키워드 검색만 제공했다. 2026-09-21 후속 작업에서 별도 로컬 인덱스를 만드는 [자연어 하이브리드 검색](SANJE-HYBRID-SEARCH.md)을 추가했다. 기존 로컬 Gemma 설명 경로와 일일 호출 제한은 유지한다. 설명 품질 평가나 새 질환 전체의 AI 생성 성공 검증을 완료했다고 주장하지 않는다.

## 검증

- Python 전체 테스트 36개 통과: 관문/Origin/입력 용량, 질환 간 사례 격리, 다중 선택, 2,096페이지, 라벨 페이징, 서명 경로/만료/비공개 정책 포함.
- 웹 lint·typecheck·단위 테스트·프로덕션 빌드 통과. 공개 소개 및 DEMO의 데스크톱/모바일 E2E 통과. 알 수 없는 질환은 HTTP 404다.
- 실제 후보 서비스에서 7개 질환의 집계·검색·상세·라벨·파일 목록, 질환별 서명 다운로드 해시를 확인했다. 근골격계 마지막 페이지 6건, COPD 기존 주소의 2,049건도 대조했다.
- 외부 Basic 인증 실계정 세션과 Google 실계정 인증 흐름을 이번 검사에서 자동 로그인하지 않았다. 인증 전 요청 차단과 인증 후 기능의 로컬 통합 검사를 구분한다.
