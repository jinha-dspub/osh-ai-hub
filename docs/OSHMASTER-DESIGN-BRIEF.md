# OSHMASTER 공개 소개·검색 DEMO

## 목적과 공개 범위

산업안전보건 표준 코드·동의어·판본별 계층을 연구자료에 연결하는 탐색 도구다. SANJE 사례 데이터와 별도 컬렉션으로 제공하며 사건 라벨이나 인과성을 자동 승인하지 않는다.

`/datasets/oshmaster`는 공개 소개·집계·승인된 3행 미리보기와 DEMO 사용법을 제공한다. `/demo/oshmaster/`의 검색·상세·파일은 기존 .3 인증 관문을 거친다. Google 로그인만으로 자료 권한을 부여하지 않는다. 사용자 요청에 따라 Hub에서 공개 소개와 인증된 서비스를 연결하며, 인수본의 기존 review/admin 메타데이터는 원본 기록으로 보존한다.

자료는 `opendata/oshmaster/releases/2026-09-21.1/`에 복사하고 원본 174개 파일의 해시를 대조했다. 데이터·검색 SQLite·전체 ZIP은 Git에 넣지 않는다. 공개 정적 JSON에는 집계와 선택한 C33/C34/C34.0의 3행만 포함한다. 전체 원 코드 98,638개, 통합 코드 80,593개, 표준 식별자 19개·표준/판본/축 조합 53개를 각각 다른 단위로 안내한다.

## 화면·디자인

OSH Family Design 1.0의 색상·Noto Sans KR·카드·버튼을 적용한다. 데스크톱은 검색 조건 → 왼쪽 결과/오른쪽 상세, 850px 이하에서는 한 열이다.

입력은 표현/코드, 분류축, 표준, 판본이다. 검색은 표준명·코드·동의어·관련 어휘를 구분하는 사전/FTS 검색이며 LLM·임베딩 자연어 의도 해석이 아니다. 원 패키지의 판본별 검색과 계층 로직을 Python 모듈로 이식하고 UI는 TypeScript로 구현했다.

상세에서는 상위/직접 하위를 탐색하고 하위 포함 여부를 선택한다. 판본과 범위를 명시적으로 확인해야 JSON을 받을 수 있다. JSON에는 demo=true, 자료 버전, case_label_approved=false를 포함한다. 검색어·필터·선택·포함 범위가 바뀌면 확인 상태를 초기화한다. 전체 선택 범위는 API 페이지를 모두 읽은 뒤 건수·ID 중복을 확인해 생성한다.

초기 로딩·검색 중·빈 결과·입력 오류·연결 실패를 구분한다. 처리 중에는 중복 실행을 막고 실패 메시지는 role=alert로 알린다. 초기 자료 조회 실패에는 재연결 버튼을 제공한다. 합성 자동화 사례에는 DEMO를 표시한다.

## 저장소·보안

별도 private `oshmaster-research` 버킷에 원 인수 ZIP(75,023,716 bytes)과 Excel 안전 CSV ZIP(21,437,860 bytes)을 버전/해시 경로로 업로드하고 원격 SHA256을 대조했다. 키는 기존 서버 비밀 설정을 사용하며 원문/키를 웹 번들에 포함하지 않는다.

서버는 고정 파일 ID만 받고 버전·버킷·경로·비공개 정책을 확인한 뒤 60초 signed URL을 발급한다. 브라우저는 Storage에서 직접 받는다. 원 자료를 웹 함수나 Python 응답으로 중계하지 않는다. 파일 바이트는 Git에 올리지 않는다.

검색 DB는 read-only SQLite로 열고 릴리스의 고정 SHA256을 확인한다. API에서 중복 필터·허용되지 않은 판본·잘못된 ID·페이지·입력 길이를 검사한다. 모든 API/자원은 기존 게이트웨이 인증을 공유하며 다운로드 POST에는 Origin·JSON·용량 검사를 적용한다.

## 자료의 한계

연구책임자·대표 연구자·갱신 담당 및 출처별 재배포 조건은 아직 확인 중이다. SANJE 연구자 정보를 이 자료에 임의 적용하지 않았다. 미연결 보조 26행, 매핑 20행, 원 판본 미기록 crosswalk 5,008행과 unresolved 탐색노드 14행을 안내한다. 코드 간 매핑을 확정 정답으로 쓰지 않는다. Hugging Face 게시 계획은 없다.

원 제공자의 개인정보·권리 전수 검토 및 매핑 의미 정확도 검수는 완료했다고 주장하지 않는다. 인수 검증 스크립트가 reports/validation.json을 덮어쓰므로 원본 검증은 별도 코드로 읽기 전용 수행했다.

## 운영·검증

- 정적 앱: `npm run build:oshmaster-demo --workspace web`. Python: 기존 `app.demo_gateway:app`에 등록. 별도 운영 포트나 nginx 변경 없이 `/demo/oshmaster/`를 사용한다.
- 재업로드: `ai-api/.venv/bin/python ai-api/scripts/upload_oshmaster_storage.py`. Storage 키·업로드 상태는 Git 제외된 local_asset에 유지한다.
- 독립 인수 검사: ZIP/174개 파일 해시·표별 행 수·기본키·미연결 기록·SQLite quick_check 확인.
- 실제 API 검사: 53개 범위/98,638개 코드, “폐암”→KCD 9차 C34 동의어, 하위 포함 22개·C33 제외, 두 signed 다운로드의 실제 원격 응답 확인.
- 자동화: 인증 우회·Origin·중복 필터·판본 격리·코드 범위·파일 allowlist·private bucket, 공개 소개·3행 표·DEMO 범위 확인·JSON 내려받기·모바일.
- 외부 Basic 인증 실계정으로 자동 로그인하거나 새 분류의 내용 정확도 평가를 완료한 것은 아니다. 배포 후 공개 소개 응답과 인증 전 차단을 별도 확인한다.

### 운영 확인 기록 · 2026-09-21

기존 .6:8103 서비스 재시작 및 health 200, 위조 사용자 헤더를 넣은 .6 직접 접근 403을 확인했다. 이 서버에서 tools.osh.ai.kr 경유 요청은 자격증명을 넣지 않아도 200이었다. 내부망 예외인지 전체 공개 정책인지 .3 설정 확인이 필요하며, 외부 방문자에게 Basic 인증이 강제된다고 검증한 것으로 보고하지 않는다. 애플리케이션의 관문 IP·사용자 헤더 검사는 유지했다.
