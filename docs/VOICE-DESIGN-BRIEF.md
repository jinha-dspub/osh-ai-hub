# 음성 안내 DEMO 디자인 브리프

상태: 구현 완료 · 실제 음성 검증은 API 크레딧 부족으로 대기 · 2026-09-18
기준: [디자인 가이드](DESIGN-GUIDELINES.md)

## 목적

시각장애인과 음성 이용을 선호하는 방문자가 사이트 사용법을 묻고 COPD 검색 결과에 접근하도록 돕는다. 첫 버전은 한 질문씩 음성으로 보내고 스트리밍 음성·자막으로 응답한다. 연속 통화와 자유로운 화면 조작은 포함하지 않는다.

## 입력과 결과

| 항목 | 결정 |
|---|---|
| 입력 | 마이크 PCM 음성 최대 20초 또는 글 300자 |
| 주요 행동 | 말로 질문하기 / 질문 보내기 / 마이크·답변 멈추기 |
| 결과 | AI 생성 음성·자막, 검증된 COPD 검색 결과 링크 |
| 느리게 읽기 | 시작 전에 선택, 음성 생성 속도 0.85 |
| 자료 처리 | 소리·질문을 OpenAI에 전송한다는 동의 필요. 서버 파일에 녹음·대화 저장 안 함. 전송용 메모리는 종료 후 최대 60초 내 제거. 브라우저 답변은 화면에 남고 새 질문·이탈 시 사라짐. 제공자 보관 정책은 별도 |
| 검색 | 서버에서 키워드 검색, AI에는 개수와 링크만 전달. 판정문·검색 결과 원문은 전송 안 함 |
| 권한 | 기존 .3 인증 관문 그대로. Google 로그인과 별개 |

## 화면

데스크톱: 소개 → 좌측 질문·동의·속도, 우측 상태·자막·결과.
모바일: 같은 순서로 한 열. 본문 16px, 주요 버튼 최소 48px. 음성이 없어도 글 질문·직접 검색 가능. 음성과 화면낭독기의 중복 읽기를 피하려고 자막 전체는 자동 낭독하지 않고 상태만 aria-live로 알린다.

| 상태 | 표시와 행동 |
|---|---|
| 초기 | 외부 AI 전송 안내와 동의, 버튼 비활성 이유 |
| 연결 | 마이크와 연결 준비, 언제든 중단 |
| 듣기 | 말이 끝난 후 1.5초 무음 또는 질문 보내기로 전송. 최대 20초 |
| 응답 | 음성 스트리밍 + 자막, 즉시 멈추기 |
| 오류 | 마이크 권한·연결·예산 초과 안내 및 직접 검색 |
| 성공 | 실제 답변과 도구가 반환한 검색 링크. AI 판단 한계 표시 |

## 예산

OpenAI 음성과 기존 Gemini 임베딩 검색을 SQLite의 공통 원장으로 제한한다. 한국시간 날짜 기준, 보수적 환산 예산 **8,000원/일**. 사용자 요청 한도 10,000원의 여유분을 남기며, 환산은 실제 환율이 아닌 3,000원/USD로 계산한다. 공급자 실제 청구액·다른 앱·Storage 요금까지 통제한다는 뜻은 아니다.

요청마다 최대 비용을 먼저 예약한 뒤 제공자 사용량으로 정산한다. 음성 응답 하나당 1,200원을 예약하고 512 출력 토큰, 20초 입력, 65초 수명, 최대 2회 응답, 동시 3세션으로 제한한다. 텍스트·캐시 토큰도 더 비싼 오디오 요금으로 계산한다. 정산 없는 취소·장애·프로세스 재시작은 예약을 환불하지 않는다. 날짜가 바뀌어도 미확인 예약이 남아 과소 계산하지 않는다. 누적 미확인 예약은 공급자 청구 확인 후 관리자가 대조해야 한다. 이 때문에 실제 청구액보다 일찍 차단될 수 있다.

## 검증과 한계

서버 예산 동시성·자정 경계·중복 정산·입력 크기·관문 위조·세션 소유자 검사를 테스트한다. 브라우저 fixture는 DEMO라고 명시하며 유료 API를 호출하지 않는다. 실제 OpenAI 연결·모바일 마이크·한국어 발화와 NVDA/VoiceOver 사용성은 별도로 확인해야 한다. 동작 검증 전에는 공개 도구 카드에 노출하지 않는다.

공식 참고: [OpenAI Realtime 연결](https://developers.openai.com/api/docs/guides/voice-websockets), [요금](https://developers.openai.com/api/docs/pricing).

## 실제 연결 확인 (2026-09-18)

서버의 실제 키로 WebSocket handshake 101은 확인했으나 `credit_balance_exhausted`가 반환되었다. 음성 생성 성공은 확인하지 못했다. Google/Gemini 키 오류가 아니라 OpenAI API 크레딧 부족이다. 그래서 음성 카드만 관리자에게 표시한다. 크레딧을 추가한 뒤 실제 발화·음성 출력·검색 함수 시험을 끝내야 공개할 수 있다. 오류가 session.created 이전에 확실히 반환되면 비용 0으로 정산한다.

빌드: `npm run build:voice-demo --workspace web`. 기존 osh-demo 서비스만 재시작하면 `/demo/voice/`를 제공한다. 키는 `.6`의 `local_asset/chagpt_dspubs.txt`에서만 읽는다. Vercel에 이 키를 넣지 않는다. 새 nginx 경로나 UFW 포트는 필요 없다.

검증 결과: 서버 27개, 웹 단위 24개, 데스크톱·모바일 E2E 24개 통과. lint/typecheck/운영 build 통과. E2E 음성 응답은 명시적 DEMO fixture이며 실제 발화 품질 검증은 아니다.
