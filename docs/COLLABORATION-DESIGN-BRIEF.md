# 협업 메뉴 디자인 브리프

2026-09-19 · OSH Family Design 1.0 · 기준: DESIGN-GUIDELINES.md

## 목적

자료를 이용하는 방문자는 데이터 찾기·분석 체험으로, 자료와 앱을 만드는 연구자·개발자는 협업으로 안내한다. 사용자의 요청에 따라 기존 상단 개발자 API를 협업으로 바꾸고 공개된 두 키트를 협업 템플릿으로 묶는다.

## 화면과 동작

`/collaboration`: 협업 소개(연구자/제작자와 개발자/앱 제작자) → 협업 템플릿(데이터 제작 가이드, OSH Family Design) → 협업 요청 → 개발자 문서/API 목록.

- 공통 파란색·Noto Sans KR·12px 카드·7px 버튼을 적용한다. 모바일은 한 열로 배치한다.
- 이메일 `jinha@dspubs.org`는 사용자가 지정한 협업 연락처다. mailto 링크와 복사 가능한 주소를 제공한다. 실제 발송·접수 기능을 구현하거나 완료 안내를 만들지 않는다.
- 문의 시 이름·소속, 자료/앱 소개·준비 상태·협업 내용을 안내한다. 실제 자료 전달 경로와 공개 범위는 논의 후 정한다.
- 데이터 찾기와 홈 자료 목록에는 연구 데이터만 표시한다. 협업 키트는 협업 화면에 표시하며 기존 다운로드·상세 URL은 유지한다.
- 두 키트 상세 화면의 뒤로가기는 협업 템플릿으로 연결한다. 기존 `/developers`, `/apis`는 협업 화면에서 접근 가능하며 메뉴 활성 상태도 협업으로 표시한다.
- 로그인·자료 권한·실제 데이터 Storage 정책은 그대로 사용한다. 양식 합성 내용은 DEMO로 유지한다.

## 검증 범위

상단 메뉴·모바일 열기/닫기, 카탈로그와 협업 목록 구분, 두 키트의 상세/다운로드·기존 API 문서, 이메일 링크, 상세 페이지 메뉴 활성 상태와 360px 화면 넘침을 확인한다. 이메일 실제 발송은 검사하거나 수행하지 않는다. lint·typecheck·unit·build 및 E2E를 실행하고 운영 배포 후 페이지와 다운로드를 확인한다.
