# 기업·기관 안전보건 공개정보 디자인 브리프

상태: 구현 완료 · 공개 반영
작성일: 2026-10-01
기준: [OSH AI Hub 디자인 가이드](DESIGN-GUIDELINES.md) · 인수 검토: [CORPORATE-OHS-INTAKE-REVIEW.md](CORPORATE-OHS-INTAKE-REVIEW.md)

## 목적

- 사용하는 사람: 안전보건 연구자, 기업 안전보건·ESG 담당자, 공시 정책 담당자
- 해결할 일 한 가지: 어느 기업·기관이 어떤 안전보건 정보를 어떤 정의·범위로 공개했는지 원문과 함께 확인한다
- 도구 설명 한 문장: 흩어진 안전보건 공개자료를 기업·업종·공통지표로 연결해 탐색하고 내려받는다
- 이번 작업 범위: Hub 소개 페이지 신규, 제작자 정적 앱은 받은 그대로 관문에서 서비스

## OSH Family Design 적용

- 적용 키트 버전: OSH Family Design 1.0 (`design/osh-family/osh-family.css`). 제작자 앱도 같은 키트(`demo/assets/osh-family.css`)를 동봉
- 공통 색상·Noto Sans KR Variable·카드 12px·버튼/입력 7px 적용: 소개 페이지 `osh-` 클래스만 사용
- 폰트 실제 로드 확인: 앱은 동봉 폰트 14조각 로드(Playwright 요청 기록)
- 앱에 맞게 달라지는 레이아웃: 소개 → 활용 3단계 카드 → 구성표 → 원천·기간표 → 파일 카드 → 해석 주의
- 공통 스타일 예외와 이유: 제작자 앱이 막대를 인라인 style로 그려 이 경로만 CSP에서 인라인 스타일 허용

## 입력과 결과

| 항목 | 결정 내용 |
|---|---|
| 입력 자료·형식·용량 | 없음(읽기 전용). 검색어·업종·원천 필터 |
| 주요 행동 버튼 | DEMO 열기, 데이터 다운로드 |
| 결과 형식 | 업종 현황 차트, 기업 상세, 지표 사전, 비교표 |
| 다운로드 내용 | RC2.2 CSV·문서 개별 파일, 전체 ZIP(356KB) |
| 근거·출처 표시 | 행마다 원문 URL·문서·페이지. 원문 PDF는 배포하지 않음 |
| 자료 전송·보관·삭제 | 이용자 입력을 받거나 저장하지 않음 |
| 로그인·권한 | 없음(공개) |

## 실제 연결 범위

- 실제로 작동하는 기능: 5개 메뉴, 기업 2–3곳·업종 2–4개 비교, 파일 다운로드
- DEMO 자료·예시 결과: 없음. 모든 값은 실제 공개자료
- 연결 준비 중인 기능: API 없음
- 확인하지 못한 외부 동작: 원문 URL의 현재 접속 여부, `.3` 요청 제한과 폰트 조각 수의 상호작용
